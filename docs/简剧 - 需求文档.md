# 简剧 - 需求文档
> 项目名称：简剧
> 仓库名称：jianju
> 对接数据源：红果短剧 Android APP（包名：com.phoenix.read）
> 项目性质：纯个人学习研究项目，非商用、不分发、不公开部署
> 核心定位：Flutter 跨平台纯净短剧客户端，**去除全部广告、双端可用（安卓 + 电脑）**

## 一、项目简介
简剧 是基于 Flutter 开发的**Android + Windows 双端纯净短剧客户端**。
项目通过对接红果短剧官方私有 API，**客户端本地 100% 过滤全部广告**，实现纯净刷短剧、纯净播放，无任何开屏、信息流、片头、片中广告。

项目仅用于软件开发学习、网络接口分析、跨端客户端开发实践。

## 二、核心功能目标
1. 一套 Flutter 代码，同时编译 **Android APK、Windows EXE**
2. 对接红果短剧完整私有 API（首页、搜索、详情、播放）
3. **全局无广告**：信息流广告、播放广告、弹窗广告全部客户端过滤
4. 主题系统：浅色模式 / 深色模式 / 跟随系统，**支持自定义主题主色**
5. 本地收藏、本地观看历史、播放进度记忆
6. 播放器倍速最高支持 **5倍速**，倍速配置全局可保存，统一在设置界面管理
7. 内置风控节流策略，降低账号/设备封禁概率
8. 所有用户可修改配置项，统一收纳在【设置界面】
9. **所有API接口、数据请求地址统一放到独立文件集中管理，方便后续修改接口地址、参数**

## 三、运行环境
- Android：8.0 及以上
- Windows：Win10 / Win11
- 开发环境：Flutter 3.24+、Dart 3.5+

## 四、详细功能需求

### 1. 首页模块
1. 拉取红果短剧推荐信息流
2. **自动过滤全部广告卡片**，只展示正规短剧
3. 下拉分页加载更多短剧
4. 展示封面、标题、简介、集数、热度
5. 点击卡片进入短剧详情页

### 2. 搜索模块
1. 顶部搜索框支持关键词搜索短剧
2. 搜索结果自动过滤广告条目
3. 结果样式与首页统一，点击进入详情

### 3. 短剧详情页
1. 展示短剧封面、标题、详细简介
2. 展示全部分集列表
3. 支持本地收藏/取消收藏（不上传服务端）
4. 过滤详情页推荐广告

### 4. 播放模块（核心）
1. 获取红果官方真实 m3u8 播放源
2. **自动剔除视频广告分片**，只播放正片
3. 播放器基础能力：
   - 播放倍速：可选 0.75x / 1.0x / 1.25x / 1.5x / 2x / 3x / 4x / 5x
   - 进度拖拽记忆
   - 全屏播放
   - 音量调节
4. 播放完毕自动跳转下一集
5. 无片头广告、无暂停广告、无插播广告
> 倍速默认值、首选倍速，在【设置界面】全局配置，播放器默认读取设置里的倍速。

### 5. 主题系统（全部配置放在设置界面，硬性需求）
APP 设置页提供主题相关配置：
1. 明暗模式选择：浅色模式 / 深色模式 / 跟随系统明暗模式
2. **自定义主题主色选择**：提供多种预设色板，支持挑选APP全局主色调
特点：
- 切换主题实时生效、无需重启APP
- 主题配置永久本地保存

### 6. 本地数据功能
全部数据**仅保存在本地，不上传服务器**（防风控）
1. 观看历史记录
2. 短剧收藏列表
3. 用户登录 Token
4. APP 全部配置项（主题、倍速、缓存策略、设备信息）

### 7. 设置页面功能（新增，所有可配置项集中于此）
> 所有用户可调参数统一放到设置界面，播放器页面只做临时快速调整，**全局默认值以设置页为准**
1. 主题设置区域
   - 明暗模式切换（浅色 / 深色 / 跟随系统）
   - 自定义APP主题主色选择
2. 播放器全局默认配置区域
   - 默认播放倍速：0.75x ~ 5x 可选
3. 缓存管理区域
   - 查看图片缓存大小
   - 一键清除图片缓存
4. 账号与设备区域
   - 重置设备 ID
   - 退出登录（清除token）
5. 关于页面区域
   - 项目版本信息

### 8. 广告过滤规则（全部客户端完成）
1. **信息流广告过滤**：识别接口广告字段，直接剔除，不渲染
2. **视频片头/片中广告过滤**：解析 m3u8，删除广告 TS 分片
3. **开屏广告**：直接跳过不加载
4. **详情页推荐广告**：全部过滤

## 五、非功能需求
1. 页面滑动流畅、图片缓存优化
2. 双端 UI 统一（Android / Windows）
3. 网络失败自动重试、请求节流防风控
4. 支持一键清理缓存
5. 主题切换全局统一生效
6. 播放器倍速设置全局持久保存，打开视频自动加载默认倍速
7. API接口地址、路径全部抽离至独立常量文件，便于后期维护修改

## 六、禁止开发内容（严格遵守学习用途）
1. 不批量爬取、不批量下载视频
2. 不搭建后端服务、不对外提供接口
3. 无分享、无分发、无商用功能
4. 无金币、任务、提现等官方冗余功能

## 七、项目风险说明
1. 红果 APP 版本更新会导致 API、签名失效，需要重新适配
2. DRM 加密视频无法解密（行业限制）
3. 高频请求仍有小概率触发风控
